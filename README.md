# Практическая работа 4 — вариант 10 Зоопарк

Консольное приложение без generics, коллекций, Stream API и лямбда-выражений. Объекты хранятся в расширяемых вручную массивах.

Реализованы:

- абстрактный `Animal` и наследники `Mammal`, `Bird`, `Reptile`;
- полиморфные звук и расчёт суточного рациона;
- вольеры с ограничением вместимости;
- защита от совместного размещения хищника и травоядного;
- добавление, просмотр, поиск, изменение и удаление животных;
- перемещение между вольерами и консольное меню с проверкой ввода;
- собственное проверяемое исключение `ZooException`.

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

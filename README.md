# Практическая работа 5 — вариант 10 Зоопарк

Расширенное консольное приложение на Java 8. Проект выполняет ограничения задания: без generics, готовых коллекций, Stream API, лямбда-выражений и многопоточности.

## Реализовано

- иерархия `Animal` с млекопитающими, птицами, рептилиями, рыбами и специализированными наследниками;
- интерфейсы `Flyable` и `Swimmable` с несколькими реализациями;
- два enum с полями и методами и дополнительные перечисления предметной области;
- универсальное массивное `EntityStorage`, расширяемое через `Arrays.copyOf`;
- вольеры, климат и среда обитания, вместимость и проверка совместимости животных;
- кормление по расписанию, склад корма и атомарная проверка нехватки;
- смотрители, ветеринарные осмотры, посетители и продажа билетов;
- сортировка вставками через собственный `AnimalComparator`;
- отчёты по корму, загрузке вольеров, больным животным и выручке;
- сохранение и загрузка из `zoo.txt`, резервная копия и пропуск повреждённых строк;
- журнал действий в памяти и в `log.txt`;
- более 15 демонстрационных объектов.

## Запуск

```bash
javac --release 8 -encoding UTF-8 -d out \
  src/Main.java src/model/*.java src/service/*.java \
  src/storage/*.java src/exception/*.java src/ui/*.java
java -Dfile.encoding=UTF-8 -cp out Main
```

При первом запуске используются демонстрационные данные. При выходе состояние сохраняется в `zoo.txt`.

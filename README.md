# Практическая работа 3

Все задания из документа собраны в одном классе как отдельные методы. `main` показывает работу методов на примерах.

```bash
javac -encoding UTF-8 -d out src/Practice3.java
java -cp out Practice3
```

Задание с вводом двух чисел запускается отдельно:

```bash
java -cp out Practice3 --input
```

В исходном документе после фразы «сформирует следующую строку» образец отсутствует. Поэтому метод `buildSequenceString` формирует последовательность чисел через дефис и отдельно обозначен в коде.

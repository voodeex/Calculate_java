# Практические работы Android на Kotlin

Вариант 10 из обоих заданий. В папке три приложения с отдельными идентификаторами и APK.

## Сборка и запуск

Откройте папку `Labs10` в Android Studio. Для сборки нужны JDK 21 и Android SDK Platform 37.0. Выберите модуль в конфигурации запуска или выполните `./gradlew assembleDebug`. APK находится в папке `build/outputs/apk/debug` соответствующего модуля.

## HttpLab10 — Альбомы

Введите номер `1` и нажмите «Загрузить альбомы». Приложение делает GET-запрос к JSONPlaceholder, показывает HTTP-код, количество результатов и названия. Для номера `9999` этот ресурс обычно возвращает 200 и пустой список. Пустой ввод проверяется до запроса. Сетевые ошибки, коды вне 2xx и некорректный JSON обрабатываются отдельно.

## JsonLab10 — Заказы

Начальные данные лежат в `res/raw/data.json`. Gson загружает три заказа в RecyclerView. Фильтр `780,00` оставляет ровно два заказа, а сортировка по убыванию выводит A-1002 раньше A-1001. Общая сумма исходных заказов составляет 17 220,50 ₽.

«Новый заказ» открывает форму. Имя клиента, город и позиции необязательны. После добавления приложение выводит весь JSON на экран и в Logcat с тегом `JSON_LAB10`. Кнопка «Сохранить и прочитать JSON» записывает и перечитывает внутренний `orders.json`. При следующем запуске используется сохранённый файл.

## RoomLab10 — Автосервис

Откройте приложение с чистой учебной базой и нажмите «Выполнить сценарий». В Logcat выберите тег `ROOM_LAB`. В сценарии 25 команд, включая проверки пустого имени, отсутствующего заказа, неверной даты и попытки записи с нарушением внешнего ключа. Для повтора используйте новый экземпляр приложения с пустыми данными.

- `masters` и `orders` связаны по `masterId` с индексом и каскадным удалением. Room хранит дату как число дней, конвертируя её в `LocalDate`.
- Через `BaseDao<T>` выполняются внесение, изменение и удаление. `addmany` работает в транзакции, поэтому при ошибке отсутствующего мастера весь пакет откатывается.
- `find` сравнивает результаты параметризованного запроса и фильтрации в Kotlin. `stat` показывает выручку, `join` связывает заказ с именем мастера, а Flow сообщает об изменении количества заказов.
- Схема Room экспортируется KSP в `RoomLab10/schemas`.

В Android Studio базу можно открыть через **App Inspection → Database Inspector**. До запуска обе таблицы пусты. После запуска должно быть 3 мастера и 2 004 заказа, из которых 2 000 созданы для замера. Выручка мастера № 1 после изменений составляет 13 600 ₽. Сравниваются 20 запусков двух способов. Индексированный SQL отбирает строки внутри базы, а `getAll().filter` каждый раз загружает все строки и обрабатывает их в приложении.

## Результаты проверки

Приложения проверены на эмуляторе Android API 36. HTTP-запрос для пользователя № 1 вернул 200 OK и 10 альбомов, а для № 9999 пришёл пустой список. Для JSON проверены строгая граница фильтра, сортировка, добавление заказа без клиента и восстановление сохранённого файла после перезапуска.

Для Room в папке `evidence` есть Logcat и снимки экрана приложения до и после сценария. Содержимое таблиц сверено по копиям SQLite из эмулятора. В этом запуске 20 выборок через Kotlin заняли 34 мс, через SQL — 15 мс. Оба способа вернули по 299 одинаковых строк.

# Практическая работа № 8

Вариант 10. HTTP «Альбомы» и JSON «Заказы».

## Сборка и запуск

Откройте папку `Labs10` в Android Studio. Для сборки нужны JDK 21 и Android SDK Platform 37.0. Выберите модуль в конфигурации запуска или выполните `./gradlew assembleDebug`. APK находится в папке `build/outputs/apk/debug` соответствующего модуля.

## HttpLab10 — Альбомы

Введите номер `1` и нажмите «Загрузить альбомы». Приложение делает GET-запрос к JSONPlaceholder, показывает HTTP-код, количество результатов и названия. Для номера `9999` этот ресурс обычно возвращает 200 и пустой список. Пустой ввод проверяется до запроса. Сетевые ошибки, коды вне 2xx и некорректный JSON обрабатываются отдельно.

## JsonLab10 — Заказы

Начальные данные лежат в `res/raw/data.json`. Gson загружает три заказа в RecyclerView. Фильтр `780,00` оставляет ровно два заказа, а сортировка по убыванию выводит A-1002 раньше A-1001. Общая сумма исходных заказов составляет 17 220,50 ₽.

«Новый заказ» открывает форму. Имя клиента, город и позиции необязательны. После добавления приложение выводит весь JSON на экран и в Logcat с тегом `JSON_LAB10`. Кнопка «Сохранить и прочитать JSON» записывает и перечитывает внутренний `orders.json`. При следующем запуске используется сохранённый файл.

## Результаты проверки

Приложения проверены на эмуляторе Android API 36. HTTP-запрос для пользователя № 1 вернул 200 OK и 10 альбомов, а для № 9999 пришёл пустой список. Для JSON проверены строгая граница фильтра, сортировка, добавление заказа без клиента и восстановление сохранённого файла после перезапуска.
